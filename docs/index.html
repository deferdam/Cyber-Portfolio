SOAR

Sigma-based behavioral detection engine built in Python. No hash signatures - pure behavior: PowerShell obfuscation, LOTL binaries, ransomware activity, persistence mechanisms, privilege escalation, and suspicious Linux commands. Lab environment only. Defensive scope.

Architecture
  • Multi-format log ingestion - Windows Event Logs, Sysmon, PowerShell 4104, RFC 3164/5424, CEF, NXLog, Winlogbeat
  • 3-layer engine - Signature / Behavioral / Correlation - with per-layer error isolation
  • Sigma YAML rules per domain - multi-file loader, paths resolved relative to module
  • MITRE ATT&CK tagging on every Signal - tactic + technique
  • Risk score 0–100, structured JSON alert output

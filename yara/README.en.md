# YARA — Detection and Classification (Learning)

This directory contains YARA rules written in the context of Blue Team training and defensive analysis.

## Objectives
- Identify known or similar samples
- Extract reliable patterns from static analysis
- Understand limitations and false positives

## Methodology
1. Binary analysis (strings, key functions, behaviors)
2. Selection of stable indicators
3. Writing simple, readable rules
4. Testing on clean / educational samples
5. Documentation of limitations

## Organization
Each subdirectory corresponds to a project or an analyzed family.  
The rules are **never used in production**.
